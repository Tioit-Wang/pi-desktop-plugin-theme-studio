侧边栏背景走专用 token --ds-bg-sidebar-image： --ds-bg-sidebar 必须保持为颜色，否则会破坏玻璃色罩、描边与 macOS vibrancy 的 color-mix。左栏是唯一开箱就能看到图片的区域。

每个表面可以单独设置背景色、渐变、图片、背景模糊与圆角。选择器取自真实外壳， 所以这里改的就是应用里对应那块。

图片存在插件自己的数据目录里，主题 CSS 直接引用它的绝对路径。 单张上限 4MB（宿主限制），每次上传都是新文件。
